# 历史数据面 routed/transport 实验（3000–7000）

> **资格已撤销（2026-07-26）**：本报告保留原始观测数据用于传输瓶颈分析，但不满足当前 `full_chain` 业务成功语义。它把大量 HTTP 5xx 计为 routed success、存在 generator dropped iterations，且 Auth、Policy、幂等副作用、Redis queue 和审计证据缺失。因此所有“稳定容量”或“≤5000 稳定”表述均不再有效，不能用于生产承诺或限额设置。

**场景**：历史 `dataplane_only` + `apisix_routed`（现归类为非资格 `transport`）  
**路径**：Windows k6 → Edge **Zentinel :10080** → **Bridge×2** → **Agent** ↔ **Connector** → Intra **APISIX** → **mock**  
**每档**：恒速 4×2min；**不含** Auth / Policy  
**7000**：采用第 2 次复测（`143731`）；第 1 次见文末附注

**当前解释（仅传输实验）**  
- 3000–5000：仅说明历史 routed 指标和发压达成率，**不构成稳定区**；5000 档仍有 141,283 个 dropped/无响应样本且绝大多数终态为 500。  
- 6000：发压和链路均出现明显饱和迹象。  
- 7000：仅约 87% 达成并有 350,560 个 dropped iteration，不能作任何稳态承诺。

## 复现命令（改 `ConstantRps` 即可扫档）

```powershell
cd D:\lxz\compile\Rust_project\Secure_Access_Gateway_SAG\sag-cloud
$env:K6_LOG_OUTPUT = "none"
$ts = Get-Date -Format "yyyyMMdd-HHmmss"
$RPS = 5000   # 3000 / 4000 / 5000 / 6000 / 7000

.\scripts\ops\run-load-dataplane.ps1 `
  -EdgeHost 172.16.9.107 `
  -RunMode dataplane_only `
  -ScenarioType dataplane_only `
  -DataplaneSuccessMode apisix_routed `
  -GateProfile dataplane_routed `
  -ConstantRps $RPS `
  -Stage1Duration 2m -Stage2Duration 2m -Stage3Duration 2m -Stage4Duration 2m `
  -PreAllocatedVUs $RPS -MaxVUs ([int]($RPS * 3)) `
  -NoCapacityVuCap `
  -SummaryJson ".\artifacts\k6-dp-$RPS-routed-$ts.json"
```
